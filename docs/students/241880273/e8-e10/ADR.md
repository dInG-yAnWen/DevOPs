# 决策记录：合并同一目标的显式依赖规则

背景与约束：GNU Make 会累积同一目标多条显式规则中的先决条件；原教学扫描器仅读取第一条，因而在随后规则声明 `main.o: config.h` 时仍误报 `config.h` 缺失。E9-B 还要求保留原来的冗余项，不应仅因多规则输入而生成补丁。

选择：对每个受支持目标收集所有匹配的显式规则，分别执行当前简单变量展开和语法边界检查，再将依赖合并到集合中并排序。这样保留现有报告结构、补丁策略和确定性输出。新增直接依赖与变量依赖测试，并在 E9-B 演示中保存独立多规则场景结果。

替代方案：继续取第一条规则会保留误报；在补丁阶段特殊忽略 `config.h` 会绕过声明分析且无法处理其他依赖；重写完整 Make 解析器超出本实验的受限语法范围。

代价与范围：只合并当前正则可识别的显式目标规则，并沿用已有简单变量展开规则。模式规则、order-only 依赖、续行、条件、函数和完整 GNU Make 求值语义不在此实现范围；无法解析的声明仍按现有逻辑拒绝。

验证：服务器镜像 `sha256:9b95e4539473c3dee251ff88149c29f8a054bab6c97ad19c07f0d02e1f340118`；定向测试 12 项通过。E9 多规则结果只有 `REDUNDANT unused.h`，补丁为空且输入字节未变。E8-B 旧报告返回 `STALE_REPORT`；E10-B 三场景门禁通过。服务器证据包 470 项文件校验通过，下载哈希与服务器一致。GitHub Actions #15 在 2026-11-10 核查时仍运行中。
