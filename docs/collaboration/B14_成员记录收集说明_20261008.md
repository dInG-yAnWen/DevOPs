## 查找已有记录

在自己的克隆目录中查看成功的 `work/` 子目录。优先查当时保存的 `source-sha.txt`、运行说明或终端记录。当前 `git rev-parse HEAD` 只有在确认运行后没有换版本时，才能用来补录当次 SHA；否则保留“当次版本待确认”。

同一服务器上的记录可直接提供路径，无需搬运整个仓库。打包时只打包成功的 work 目录，保留其中已有日志和摘要。

## 需要补跑时

若找不到当次源码版本或成功日志，使用新的学号目录补跑，保留旧目录。将 `填写自己的学号` 替换为本人学号，在服务器 Bash 中执行：

```bash
(
set -eu
student_id=填写自己的学号
stamp=$(date +%Y%m%d-%H%M%S)
clone_dir="/root/$student_id/draft-e4-$stamp"
mkdir -p "/root/$student_id"
git clone https://github.com/dInG-yAnWen/DevOPs.git "$clone_dir"
cd "$clone_dir"
git checkout --detach eb2c62c9a3222cbcb25a8bc204348ce91b3c9ba8
git config --local user.name "$student_id"
git config --local user.email "$student_id@localhost"

run_dir="work/$stamp"
mkdir -p "$run_dir"
git rev-parse HEAD > "$run_dir/source-sha.txt"
git remote -v > "$run_dir/remote.txt"
printf 'student_id=%s\nclone_path=%s\nevidence_path=%s\n' \
  "$student_id" "$PWD" "$PWD/$run_dir" > "$run_dir/member-record.txt"

set +e
make -j1 RUN="$run_dir" all 2>&1 | tee "$run_dir/make-all.log"
result=${PIPESTATUS[0]}
set -e
printf '%s\n' "$result" > "$run_dir/make-all-exit.txt"
printf '运行退出码：%s\n证据目录：%s\n' "$result" "$PWD/$run_dir"
exit "$result"
)
```

组内构建尽量错开。对照重点是源码版本、工具链、测试和冒烟结论；镜像 ID、耗时和日志行数允许不同。假 Key 检查按 B 组手册第 6 节另行留存负例与清理后的日志。
