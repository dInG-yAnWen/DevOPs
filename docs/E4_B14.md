# B14 E4 Service Environment

This repository keeps the B14 E2 and E3 records and now adds the E4
reproducible environment for the DRAFT service.

## Layout

- `services/draft/`: service CLI, smoke test and unit tests
- `fixtures/draft/`: TinyGreeting build fixture and broken/reference Dockerfiles
- `compose.yaml`: resource limits and Docker socket handoff for DRAFT
- `Makefile`: doctor, build, test, smoke, scan and all
- `work/<timestamp>/`: local evidence output, ignored by Git

## Commands

Run these commands from the repository root on the B14 Linux server:

```sh
make doctor
make build
make test
make smoke
make scan
make all
```

The Dockerfile uses fixed digest references through
`m.daocloud.io/docker.io/...` because the server cannot reach Docker Hub
directly. Its Debian package source is rewritten to the Alibaba Cloud mirror
with retries because the server's route to `deb.debian.org` is very slow.
Do not add real keys to `.env`, Git history, Dockerfile, or logs.
